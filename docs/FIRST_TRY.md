# Optional beta feedback

Follow the [three-step quick start](QUICK_START.md), then click **Run**. Try a heatmap cell and **Multi → Run** if you have time.

Tell us:

- Your VMD version and operating system.
- Did the example open and Run finish without editing paths?
- Was anything confusing or visibly wrong?

[Open an issue](https://github.com/AntunesLab/rmsx-flipbook-vmd/issues). **Quick Check → Save report…** can provide diagnostics; inspect the report for local account or dataset paths before sharing.

Feedback is welcome, not a prerequisite for trying the beta. Independent first-time testing was waived for the developer handoff; that waiver is not a test pass. Technical qualification remains documented separately in [Verification](VERIFICATION.md).
